# Online Merchandise Store

An online merchandise store sells T-shirts for $28 each and hats for $18 each. The store charges a $3 shipping fee for every item ordered and applies a 7% sales tax to the merchandise subtotal. The number of shirts bought should be 3 and the number of hats bought should be 2.

Your program should:

1. Calculate the total cost of the shirts and hats.
2. Calculate the merchandise subtotal.
3. Calculate the total number of items ordered.
4. Calculate the total shipping cost based on the number of items.
5. Calculate the sales tax on the merchandise subtotal.
6. Calculate the final amount paid by adding the merchandise subtotal, shipping cost, and sales tax.
7. Print the merchandise subtotal, shipping cost, and final amount paid using `str()` and the `+` operator.

Do not type any of the calculated answers directly into the `print()` statements. The program must calculate each amount using the given variables.

## What This Problem Assesses

This question assesses a student's ability to use variables and arithmetic operations to solve a multi-step real-world problem. It requires the student to calculate separate costs, store the results in variables, and use those variables in later calculations.

The most challenging part is breaking the problem into the correct steps and deciding which values belong in each calculation. Shipping depends on the total number of items, while sales tax depends on the merchandise subtotal. Completing the problem gives practice turning written instructions into a sequence of Python calculations.

## Answer Key

The complete answer is in `solution.py`. The merchandise subtotal is $120, shipping costs $15, sales tax is $8.40, and the final total is $143.40.
